# Mini Nest

> 🎓 Учебный проект по изучению TypeScript Decorators, Metadata и внутреннего устройства NestJS.

---

# 🎯 Цель проекта

Цель проекта — **не написать собственный NestJS**, а разобраться, как он устроен внутри.

В ходе разработки мы своими руками реализуем основные механизмы, лежащие в основе NestJS:

- работу декораторов;
- собственное хранилище метаданных;
- регистрацию маршрутов;
- поиск контроллеров;
- простой роутер;
- Guards на основе metadata.

После завершения проекта я должен понимать:

- как работают все виды TypeScript Decorators;
- зачем существует `reflect-metadata`;
- как NestJS хранит и читает metadata;
- как происходит регистрация маршрутов;
- как работают `@Controller()`, `@Get()`, `@Post()`, `@Roles()`;
- как самостоятельно написать подобный механизм.

# 📌 Правила проекта

- Не использовать `reflect-metadata` до завершения собственного Metadata Storage.
- Не копировать код NestJS.
- Максимально понимать каждое архитектурное решение.
- Минимизировать использование `any`.
- После каждого Sprint проводить Code Review и рефакторинг.
